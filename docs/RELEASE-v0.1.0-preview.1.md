# v0.1.0-preview.1 — bounded offline FDD inspection

First MIT-licensed synthetic preview. Download complete self-contained Windows x64
or Ubuntu24.04/glibc x64 bundles and verify signed checksums before use.

Declared runtime/deps/RID, entry metadata, observed PE/ELF header diagnostics and
optional exact file inventory, with a five-case synthetic demo and JSON/text reports.
Owned metadata child with deadline, concurrent bounded drains and strict receipt;
read-only snapshots, source-change recheck and fresh-report guards.

Only trusted-origin target packages; no target execution/Assembly.Load, malicious
PE sandbox, installed-runtime/host resolution, dependency/ABI/startup guarantee,
signature validation, scanner, repair, download/install or production claim.
Input provenance remains UNVERIFIED; SSH release provenance is separate from OS
binary signing and the inspected target's trust. Binaries are not Authenticode-signed.

Exact source, matching-OS CI and already-executed package archives are required;
release aggregation does not rebuild them. SHA256SUMS covers three archives, with
the public key and file-namespace SSH checksum signature supplied separately.
