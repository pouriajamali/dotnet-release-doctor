# Contributing

Start with the synthetic demo and README tests. Report release/commit, OS, exact
command, expected/actual reason/exit and a smallest trusted **synthetic** reproduction.
Do not upload private builds, customer files, configuration secrets or account data.
Keep failed evidence; report unsupported cases honestly.

Preserve static-only operation, trusted-input boundary, owned worker and complete
receipt requirement. No target execution, Assembly.Load, arbitrary plugin/command,
network resolver, package installer or automatic repair belongs in this preview.
Add a meaningful failure-boundary regression for a behavioral change, retaining
source invariance, caps, no raw paths/config and truthful optional not_checked.

Do not rewrite tags/checksums, replace historical assets, weaken signing or alter
unrelated portfolio/client files. MIT permits reuse under its terms; retain the
original copyright and upstream notices. Source/CI/signatures are not customer,
runtime, safety, revenue or independent-skill proof.
